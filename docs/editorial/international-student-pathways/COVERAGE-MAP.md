# Coverage and search intent

26 November 2026 public baseline. All five localized Guide API listings contained the same 75 slugs (375 variants), and the public sitemap contained 425 canonical URLs. The audit read all 220 localized details for 44 relevant Guides selected from education, family, work, settlement and related tax, banking and employment topics. The remaining Guides were screened by category, localized title and summary. The public University category returned no Guide rows. The local University plan lists nine unpublished admissions and Student Guides. The catalogue expansion audit already identifies Graduate Visa as gap W3 and proposes `graduate-visa-uk`. No matching dedicated Guide was found in the reviewed repository editorial catalogue or available local handoffs. Protected private inventory must still be reconciled by the standard publisher before writes.

## Existing navigation

The public Work Visa hub and backend sitemap support `work-visa`. Detail paths use `/<locale>/work-visa/<slug>`. The React Work Visa hub and its bespoke reading journey are configured for the existing Skilled Worker series. Their current curated cards should be checked for a direct, localized entry to the new pathways cluster before public release. The draft Guides cross-link and use only existing public destination slugs otherwise. No frontend, University, family or other current Guide revisions are included.
