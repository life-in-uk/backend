栏目与九个分类页

统一栏目拟名「家庭服务与保险」，英文 Household Services & Insurance，拟用
household-services 作为一个 Guide domain 和一个 API category。九个主题是编辑分组，
如 Education Hub 的主题分组。栏目可以先展示分组卡片，未来可为每组增加落地页。
拟占位地址 /{locale}/household-services/{topic} 只用于讨论导航；Guide 仍使用
/{locale}/household-services/{guide-slug}，不再加一层分类。下列 topic 与文章
slug 不重名。独立分类页、导航、路由、sitemap 和发布清单需要未来单独评审。

分类页通用顺序

1. 显示适用地域、一句话范围和关键入口，例如车辆上路法定要求、查宽带地址、
   燃气泄漏应急入口或北爱单独市场。
2. 三个读者入口「第一次办」「已有合同」「出了问题」连到经过审阅的文章。选项按
   办事顺序排；给出中英术语、空白对照表和简明清单，官方查询与投诉入口易找。
3. 可选商业位只在版式预留。置于独立资料与任务已完整展示之后，位于一个可单独
   隐藏的边界内。宽带、手机、能源分类在总费用清单之后；保险类在条款与消费者
   权利之后；50+ 专题默认保留在设计稿，后续需单独评估版面与读者脆弱性。
   空状态不渲染。正文、FAQ、证据、排序和结构化数据不依赖该位。
4. 需要合法启动时，业主另行批准。若构成广告，启用之前应以五语就地显示清楚的
   「广告 / Ad」识别，不把通用页脚、含糊说明或仅写 affiliate 当作充分披露。
   金融推广与保险分销是两项分别判断的合规问题。详见第三份文件。
   [COMP01–COMP06]

生产顺序

P0 · 首批四篇，均附简体中文草稿。车险先解决上路前的法定要求；住宅险解决
房东/房客、贷款和楼宇责任；宽带与能源解决短时间内要签约、迁移或换供应商的问题。
编辑验收应优先核对车险地域与未投保后果、能源换供补偿与应急入口、宽带期满通知与
换网例外，以及保险如实答问、续保比较渠道、取消权和投诉时限。

P1 · 手机 SIM 与携号转网、家庭紧急维修保障、宠物险；各先做一篇主文。
它们补齐入住通信、故障处理及高损失风险。紧急维修稿须逐一核定所描述的产品
究竟是保单、服务合同还是组合；宠物稿须验证既往病症、限额与共付不会被简化。

P2 · 人寿保险，然后 50 岁以上人寿保险；先用普通寿险文章解释期限和承保，再写
免健康问询的产品。优先复核易误读的赔付条件、撤销与中断、身故保障与殡葬计划。
其余二级文章按问题日志和编辑带宽规划，确定读者任务足够独立才生产。

每波顺序是简中审阅 → 锁定源修订及 canonical hash → 四语
翻译包 → 五语逐项对照、独立审核记录绑定 hash → 学习区同类的私稿可见性验证
→ 人工批准与单独发布决策。首批四篇未来完整覆盖五语时是 20 个变体；本包仅
四个 zh-CN 文字稿。源英文专有名词、法律条件、时限、地域及依据定位五语一致，
保留 en 对外 hreflang en-GB，乌尔都独立核对 RTL、数字与英文术语方向。
